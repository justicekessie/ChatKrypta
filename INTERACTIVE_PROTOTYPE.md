# Krypta Chat — Interactive Prototype Specification

## Prototype Goal
Validate that a user can securely message with minimal friction while understanding privacy states.

## Primary Scenario (5–7 minutes)
1. User opens app and completes onboarding.
2. Enables biometric unlock.
3. Views chat list with one locked conversation.
4. Opens locked conversation (gibberish/obfuscated state).
5. Authenticates with Face ID/fingerprint.
6. Message content decrypts and becomes readable.
7. User replies, sends image, enables disappearing messages.
8. User navigates to settings and toggles hidden previews.

## Required Frames
- Splash
- Onboarding step 1–3
- Login/verify
- Biometric opt-in modal
- Chat list
- Locked chat state
- Unlocked chat state
- Media picker sheet
- Disappearing timer menu
- Group settings
- Privacy settings

## Click Targets & Interactions
- Back navigation consistency on all stack screens
- Modal close gestures
- Tab navigation persistence
- Chat item long-press context menu

## Usability Validation Checklist
- Can user tell what is locked vs unlocked?
- Can user unlock in <2 steps?
- Is send-message flow obvious without tutorial?
- Are privacy settings easy to discover?

## Deliverables
- Figma prototype link
- Interaction notes per key frame
- 1-page findings summary from 5 pilot users
