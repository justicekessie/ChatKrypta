# ChatKrypta

Planning package for a premium privacy-first messaging app concept.

## Included
- `PRODUCT_VISION.md` — product strategy, UX direction, feature roadmap.
- `DESIGN_SYSTEM.md` — mobile design system foundations and component model.
- `INTERACTIVE_PROTOTYPE.md` — clickable prototype scope and validation checklist.
- `CLAUDE_PROMPT.md` — ready-to-use prompt to generate detailed design outputs in Claude.

## Notes
- For confidentiality, use end-to-end encryption (not hashing).
- Biometric authentication can be used as a local reveal gate for sensitive chats.
